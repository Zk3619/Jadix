# Jadix Markdown

在同一份文档中写作与预览。点击段落编辑源码，离开后恢复排版。

## 写作

支持 **粗体**、*斜体*、~~删除线~~、`行内代码` 和 $E=mc^2$。

- [x] 文档坐标、撤销与重做
- [x] 表格和代码围栏按完整块编辑
- [x] 数学、化学与分子图形
- [ ] 可直接点击复选框，修改可以撤销

1. 有序列表
   - 嵌套项目
   - 带 **粗体** 的项目

Markdown **粗体** 与 <span style="color:#9b3ed1">HTML 颜色、<sup>上标</sup>、<em>嵌套样式</em></span> 在同一段落混排，公式 $x^2$ 输出矢量图。

| 内容 | 查看 | 编辑 |
| :--- | :--- | :--- |
| Markdown | 语义排版 | 实时 / 源码 |
| HTML | 系统浏览器 | 富文本 |
